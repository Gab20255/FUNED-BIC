- Análise Automática de Similaridade entre Artigos Científicos

Projeto de Iniciação Científica – Inteligência Artificial & Processamento de Linguagem Natural

Este projeto tem como objetivo analisar de forma automática mais de 20 artigos científicos, identificando temas em comum, padrões de similaridade e agrupamentos temáticos antes mesmo da leitura completa.
A solução foi desenvolvida utilizando técnicas modernas de Processamento de Linguagem Natural (PLN) e clusterização, permitindo acelerar e otimizar o processo de revisão bibliográfica.

- Objetivos do Projeto

Identificar temas centrais compartilhados entre artigos científicos.

Reduzir leituras redundantes através da detecção automática de similaridade textual.

Criar visualizações claras que ajudem na interpretação dos agrupamentos.

Automatizar processos de pré-análise textual utilizando IA.

- Técnicas e Ferramentas Utilizadas
- Processamento de Linguagem Natural (PLN)

Tokenização

Stemming

Remoção de stopwords

Vetorização dos textos (TF-IDF)

- Clusterização

K-Means

Clusterização Hierárquica (Dendrograma)

Coeficiente de Jaccard (Tanimoto)

- Modelos de Regressão

Construção e análise de modelos de regressão para investigar padrões entre métricas textuais.

- Visualização de Dados

Gráficos com Matplotlib

Mapa de calor de similaridade com Seaborn

Quanto mais clara a cor, maior a similaridade entre artigos.

Dendrograma para representação das conexões temáticas entre textos.

- Principais Resultados

Identificação automática dos temas mais recorrentes entre os artigos.

Criação de um mapa de calor representando a similaridade de todos os pares de textos.

Construção de um dendrograma mostrando o processo de clusterização hierárquica.

Agrupamento de artigos por proximidade temática, facilitando a leitura direcionada.

Relatórios técnicos completos da análise.
